# NSFC 申请书辅助 Skills

这是一个遵循 [Agent Skills](https://agentskills.io) 规范的 NSFC 申请书辅助技能集合，覆盖写作指导、图表制作、文献管理和政策速查。

本项目已投入实战，用于真实申请材料的文献检索、结构审阅、逻辑核对、Draw.io 图表制作和提交前检查。实战使用不等于结果背书；所有内容仍须由申请人核实、判断并承担责任。

## 技能概览

| 技能 | 主要用途 |
| --- | --- |
| [nsfc-write](./nsfc-write/SKILL.md) | 选题、摘要、立项依据、研究内容、方案、创新与研究基础的写作指南 |
| [nsfc-figure](./nsfc-figure/SKILL.md) | 生成可编辑的 Draw.io 概念图、技术路线图和研究基础图 |
| [nsfc-literature](./nsfc-literature/SKILL.md) | 使用 OpenAlex 检索文献，并用 wenxian 生成引用 |
| [nsfc-policy](./nsfc-policy/SKILL.md) | 2026 年度限项、AI 使用、申请代码和项目类型等政策速查 |

## 使用

将整个仓库或所需的单个技能目录安装到支持 Agent Skills 规范的工具中，也可以让兼容该规范的助手从仓库地址安装：

```text
https://github.com/njzjz/nsfc-agent-skills/
```

每个技能都可以独立使用，也可以围绕同一份申请材料组合使用。
